## 単体モック

`index.html` をブラウザで開く静的な特集プレビューです。外部ライブラリ、通信、保存、本体への変更はありません。フォントはリポジトリ内の既存ファイルを相対パスで参照します。ローカルサーバーを使う場合の URL は `http://127.0.0.1:56076/mockups/whats-new-ui-s-2/` です。

## 操作

- 上部の4章タブ、または下部の「前へ」「次のシーンへ」で切り替えます。章は自動で進みません。
- 各章の再生／一時停止アイコンでデモを停止・再開し、円形矢印アイコンでその章の操作を最初から見られます。デモ内の操作ボタンを触ると自動再生が止まり、手動で試せます。
- PCの章では左レールの検索、左右矢印、×を操作できます。現行構造と同じくページは左、タイムラインは右です。
- モバイルの章ではホームを長押しして一覧を開き、指を滑らせて候補上で離します。ホームのタップは上部へのスクロールです。キーボードではホーム上で `↑` / `Shift+F10` で開きます。リストとアンテナは候補の枝を開きます。
- 検索の章ではドック内の検索アイコンでフォームを開閉できます。入力途中の文字は開閉しても残ります。
- テーマ切り替え、手動の「動きを減らす」、OSの動き軽減設定に対応します。非表示のタブではデモの時計を一時停止し、再表示で続きから動きます。
- 最後の「特集を終える」から終了画面に進み、「はじめから見る」で再表示します。

## 構造の参照

画面の説明は `packages/frontend/src/components/hataskey3/Hk3App.vue`、`Hk3SideWorkspace.vue`、`Hk3MobileDock.vue`、`Hk3Composer.vue` を元にしています。投稿や検索の内容は説明用のサンプルです。ここで操作できるのはプレゼンテーション用の簡易デモで、Hataskey 本体の機能実装ではありません。
