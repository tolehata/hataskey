# UI S フォーム内の絵文字・添付モック

`index.html` を開くと、絵文字ボタンとクリップから投稿欄が伸縮する操作見本を確認できます。PC は投稿欄を上／下へ切り替えられます。モバイルはナビと同じガラスのケース内で下部固定です。ダーク／ライト、短い画面でのスクロール、OS の動き軽減に対応します。下書きと選択位置を保持し、絵文字は選択範囲に挿入します。戻る矢印または Escape でメニューを閉じます。

ピッカーは現在の `MkEmojiPicker.vue` の可視構成を参考に、検索、ピン留め＋パレット歯車、最近使った、カスタム絵文字の件数付きフォルダ階層、Unicode 絵文字の件数付きカテゴリを並べています。既存の4タブは CSS で非表示なので、このモックでも出していません。絵文字・名前・エイリアスはこのファイル内の少量のサンプルです。カスタム絵文字画像はリポジトリ内の `sweets_monos` SVG を参照します。`:name:` はその文字列、Unicode は表示される複数コードポイントを含む文字列を本文へ挿入します。歯車は案内のみです。

クリップには現行の「アップロード」「ドライブから」「URLから」をアイコンと左寄せのラベルで示します。各操作はサンプルの添付チップを追加するだけで、削除と16件上限を試せます。ファイル選択、アップロード、URL取得、API、投稿、保存、外部通信はありません。送信ボタンも案内だけを表示します。

実装へ進む場合の調査範囲は `Hk3ComposerEmojiPicker.vue` の `MkModal` ラッパーと `Hk3Composer.vue` のメニュー配置です。共有の `MkEmojiPicker.vue` を再利用し、埋め込み位置と見た目だけを調整する想定です。絵文字は `text`、添付は `DriveFile` の `fileIds` として独立しており、モックで混同しません。`visibility` と `localOnly` は現行の値・挙動を保つ必要があります。このモックは公開範囲や連合送信を実行しません。

Docker内のオフラインDOM検証で、構成、選択範囲へのUnicode（結合文字を含む）・カスタム絵文字の連続挿入、メニュー切り替え、添付16件上限と削除、モバイルの下部固定、Escapeとフォーカス復帰、テーマ変更、通信を行わないことを確認しました。描画・実機タッチ操作は未確認です。参照するローカル素材7件の存在も確認済みです。

コードはリポジトリと同じAGPL-3.0-only。書体RighteousはSIL OFL 1.1（`../../packages/frontend/assets/fonts/Righteous-OFL.txt`）です。SVG素材は既存のリポジトリ内ファイルへの参照で、再配布用コピーや新しい依存は追加していません。
