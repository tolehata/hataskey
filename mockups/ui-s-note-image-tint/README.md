# UI S · ノート画像の余韻

`index.html` をブラウザで開く独立静的モック。ビルド・サーバー・追加依存は不要です。同じフォルダーの `styles.css` / `mock.js` を使用します。本体には接続しません。

## 操作

- 「海 / 夕景 / 森」で最初のノートの画像を切り替えます。3枚はこのモックでCanvas描画した風景イラストで、すべて実際の画素抽出を通します。
- 「画像を選ぶ」でローカルのPNG・JPEG・WebPをプレビューできます。選択のキャンセル・読み込み失敗時は現在の画像を保持します。
- 「色の強さ」は既定40%、0〜40%。「ノート背景に色を映す」のオン／オフで全ノートを比較できます。
- ダーク／ライトに対応。初期テーマはOS設定に合わせます。幅760px以下では設定をTLの上に移動します。

## 処理と制約

- 画像全体を透明な64×64 Canvasに縮小し、各辺の約8%（5px）だけを読みます。中央の色は対象外です。
- alpha 224未満の画素を除外し、残りはRGBとして扱います。低彩度・極端に暗い／明るい画素も除外。12個の色相帯で支配的な色を求めます（異なる色を単純平均しません）。各帯の採用には縁画素の3%以上・2画素以上の有効色が必要です。
- 左右上下を個別に採用。適した色のない辺は縁全体の支配色を使い、全体に適した色がなければ透明にして通常背景へ戻します。透明画像や白黒画像に架空のアクセント色は付けません。
- 4つのradial maskとblurで淡いグラデーションを背景だけに重ねます。本文・アバター・画像にはフィルターや色変更を適用しません。背景色は650msで混ざりながら遷移し、OSの「動きを減らす」では即時更新します。
- 入力上限は20MiB、40MP、一辺32,768px。最初の512KiBの画像ヘッダーで形式と寸法を確認してからデコードします。巨大・破損・寸法を確認できない画像は拒否します。GIF・SVG・HEICは対象外。JPEGではEXIF IFD0のOrientationを読み、向き5〜8は寸法を入れ替えて縮小サイズを計算します。アニメーションWebPは静止プレビューです。
- `createImageBitmap` がある環境では長辺1,200pxを目安に縮小デコード。幅だけを指定し、高さはデコーダーが回転後の比率から決めるため、両寸法指定による歪みを避けます。ヘッダー範囲内にない／不正なEXIFは向き1として見積もりますが、片寸法指定なので比率を保ち、デコード後に再度長辺1,200px以内へ縮小します。Bitmap非対応環境は16MPまでに制限して画像要素でデコード後に縮小します。デコーダー内部のメモリ使用量はブラウザに依存します。
- 選択世代を確認して古い非同期結果を捨てます。旧ブラウザの保留中読み込みは選択変更で中断し、Bitmapは終了時にclose、Object URLは差し替え・失敗・画面離脱時に解放します。
- ファイル名や画像データをHTML文字列へ挿入しません。選択画像はCanvas経由のPNGとして表示。外部通信・API送信・永続保存はなく、CSPでも通信を禁止します。サイドナビ・リアクション・ノート操作は配置見本です。

## 検証

既存のキャッシュ済みNode / HappyDOMで、スクリプト構文、代表画素による縁抽出・fallback、数値上限、画像ヘッダーとEXIF回転寸法、テーマ・強度切替、ローカル選択の成功・失敗・競合・キャンセル、Bitmap / URL解放を確認。HappyDOMではCanvas描画とデコードをstub化し、3枚とも画素取得の処理経路を通ることを確認します。ブラウザ自動操作・実機の目視検証・実デコーダーによる画質検証は未実施です。追加パッケージは入れていません。

ブランドは隣の `../ui-s-post-banner/Righteous-Regular.woff2` を参照し、不在時はシステムフォントへ戻ります。CSPの `font-src 'self'` でローカルフォントを許可。動的な色変更は `element.style.backgroundColor` / `style.setProperty` によるCSSOM操作で、HTMLのstyle属性文字列やcssTextの挿入は使いません。`style-src 'self'` でもstyleプロパティの直接変更は許可されます（[MDN](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Content-Security-Policy/style-src#violation_cases)）。
