親指の近くで、選んで戻る。

  1. タップで上部へ、長押しで一覧ホームの短いタップで、TLの種類を変えずに表示中のタイムライン上部へ滑らかにスクロールします。約500ms長押しすると一覧が開きます。開いているときは×のタップで閉じます。「動きを減らす」が有効な場合は上部へ即時移動します。
  2. 8種類から選ぶリスト／アンテナは3件の候補へ。指を離さず少し留まると開き、そのまま滑らせて選べます。←で戻り、歯車から設定の見本へ。
  3. 選択して、滑らかに閉じるガラスのケースが縮み、書きかけの入力欄へ戻ります。
操作の補足

キーボードは Tab で ▲ に移動し、Enter / Space で開けます。ホームで Alt + ↓ も使用できます。

一覧内は ← → ↑ ↓ / Home End で表示順に候補へ移動、Enter / Space で選択。Tab で←・歯車・下部の×へ移動できます。Esc は指の操作を取消、分岐ではひとつ戻り、ルートでは閉じます。外側タップや×でも切替せずに閉じ、フォーカスは開いたボタンへ戻ります。

長押し成立前に指が10pxを超えて動いたとき、スクロール・操作中断・画面離脱時は取り消します。成立後は指の下の候補だけをハイライトし、項目上で離すと確定します。

ホーム上や候補外で指を離しても切り替わりません。一覧は開いたままなので、そのあとタップでも選べます。指を保持したまま一覧の上下端へ寄せるとスクロール。指を離してから一覧を普通にスクロールすることもできます。
