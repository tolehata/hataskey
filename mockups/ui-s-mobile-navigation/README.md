# UI S モバイルナビゲーション：浮いたガラスのケース

`index.html` だけで動く静的モックです。本体への通信・保存・追加依存はありません。

## デザイン

- 投稿フォームと5ボタンのナビを一枚のすりガラスでつなぎ、画面下端と左右に余白を空けて浮かせています。
- ホームを長押しすると、ケースが上へ滑らかに伸び、入力欄がTLの2列メニューに入れ替わります。選択やキャンセル時は逆方向に戻り、入力内容を保持します。
- メニューはアイコンと短い名前だけです。説明や重複した閉じるボタンは置かず、ホームから変わる×で閉じます。
- ナビの順番はメニュー・ホーム・通知・検索・投稿。ホームのすぐ右に9pxの▲を添え、それぞれ独立した44pxの操作領域を設けています。
- 一覧右上にペンを常設。通常はアイコンと短い名前を維持し、編集時だけ各項目の右に44pxのドラッグハンドルを表示します。ペンは完了のチェックに変わります。
- ペンの操作領域を含めて4行に必要な高さまで自動で伸び、低い画面では通知・RSSの下に収まる高さでリストをスクロールできます。
- 2列のTLの初期順は左上からアンテナ・チャンネル／リスト・外部／グローバル・ソーシャル／ローカル・ホーム。選択状態は控えめな色とチェックで示します。
- リスト／アンテナには1列3件の候補ビューを用意。短い見出し、戻る←、歯車だけのツールバーに切り替わり、ルートのペンとは区別します。設定の見本は管理対象と「変更・保存は行いません」の案内を表示します。
- 分岐の切替は240msの淡い横移動とフェード、ケースの高さは既存の滑らかな伸縮を使用します。逆方向へ戻り、動き軽減時は即時に切り替わります。
- ダーク／ライト、通知とRSS、セーフエリア、画面が低い場合のリストスクロール、OSの動き軽減に対応します。

## 操作

- ホームの短いタップで、選択中のTLの種類とノートを保持したままタイムライン上部へ滑らかにスクロールします。OSの「動きを減らす」が有効な場合は即時移動します。約500ms長押し、または▲のタップで一覧を開きます。
- 長押しから指を離さず候補へ滑らせ、候補上で離すと確定します。指を離してからタップでも選択できます。
- リスト／アンテナをタップしてもTLは変えず、見本3件の候補へ進みます。選んだ名前と種類をフィードに表示し、最後の候補選択をページ内で保持します。
- 長押し中はリスト／アンテナの上で300ms留まると分岐へ進みます。ホームのpointer captureとフォーカスを保持し、そのまま指を候補へ滑らせて離すと確定します。分岐だけで離した場合は候補ビューを開いたままにします。
- ビュー切替直後は指下の候補をハイライト・確定せず、切替時の位置から10px以上のpointermoveを確認してから選択対象にします。←と歯車も指を滑らせ、300msの滞留またはその上でリリースして進めます。戻るを同じ位置で連続発火させません。
- 分岐の←はルートへ、設定の←は候補へ戻ります。歯車は静的な設定見本への入口です。分岐／設定で並び替えはできず、API通信・実アカウントの設定画面への遷移・設定保存はありません。
- 候補外で離したときは確定せず、一覧を開いたままにします。上下端へ指を寄せるとスクロールできます。
- 編集中は右端のハンドルからタッチ／マウスで並び替え、チェックで編集を終了します。項目のタップではTLを切り替えません。8px未満の移動は並び替えず、長押し選択中のペン操作やドラッグ直後のクリックも抑止します。
- 編集中は項目またはハンドルにフォーカスしてAlt＋↑↓（同じ列の2位置）／←→（1位置）でも並び替えできます。位置をariaラベルとライブ通知で伝え、Tabはペン／チェックとハンドルも巡回します。
- 並び替え中のpointercancel・capture喪失・候補外でのリリース・別の指・リサイズ・画面離脱は、そのドラッグ開始時の順番へ戻します。上下端での自動スクロールにも対応します。
- 下部の×と外側タップは選択を変えずに閉じます。Escは指の選択／並び替え中なら操作を取り消し、編集中なら編集を終了、分岐／設定ではひとつ戻り、ルートでは一覧を閉じます。
- 順番はこのページを開いている間だけ保持。再読込で初期の逆順に戻り、実アカウント設定やAPIへ保存しません。選択候補・矢印移動・指のハイライトも新しい順番に追従します。
- キーボードの↑↓はルートでは同じ列、分岐では1件ずつ、←→は隣の候補、Home／Endは先頭／末尾へ移動します。Tab／Shift＋Tabは表示中の×・ペンまたは←・歯車と各候補を巡回し、Enter／Spaceで操作できます。非表示ビューへフォーカスを逃がさず、←でルートへ戻ると元の分岐項目にフォーカスします。
- 滞留先から離れるとdwellを取消、ビュー切替・閉じる・resize・pointercancel・capture喪失・画面離脱時は関連するdwell／切替タイマーを破棄します。中断と遅延した合成clickはTLを確定しません。
- 開いている間は入力欄と背景、×以外のナビを操作不可にします。フォーカスと長押しのpointer captureを維持し、キャンセルやフォーカス離脱で誤確定しないようにしています。
- 初回ガイドは「タップで上部へ、長押しでTLメニュー」と指を離さず滑らせる操作を短く案内します。自動では消えず、「わかった」・一覧を開く・入力を始める操作で閉じます。上部から再表示できます。
- 投稿ボタンは入力欄へフォーカスします。送信ボタンは通信せず見本の案内だけを表示し、文章を残します。

## 確認範囲

JavaScript構文と既存4検証（開閉・2列選択・下書き保持・素早い再展開・長押し選択・pointercancel・動き軽減）に加え、ペン／チェック・編集時の誤選択抑止・タッチ／マウス並び替え・端の自動スクロール・タッチ操作中断・Alt＋矢印・aria位置・Tab巡回・並び替え後のTL選択／Home／長押し候補／ハイライト・低い画面の高さ上限と通知／RSS維持をDOMで確認しました。DOM検証はHappy DOMで行ったもので、レイアウトや実機のタッチ表示の検証ではありません。ブラウザ自動操作・localhost配信は実施していません。

短いタップの変更では、現在のTL・ノート・選択状態・下書きの保持、フィード上端へのsmooth／動き軽減時のinstant指定、×による閉じる操作、長押し後のクリック抑止をDOMで追加確認しています。
