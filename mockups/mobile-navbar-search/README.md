# モバイルナビの検索モーフ

`index.html` を開く静的モック。左は Hataskey UI の独立した浮遊ピル、右は UI S の投稿欄とつながったガラスカプセル。どちらも検索アイコンから入力欄が現れ、検索後に結果パネルが上へ伸びます。上部の RSS と通知は配置を保ちます。

検索アイコンで開き、下部ナビの×で閉じます。検索行はアイコン付きの対象選択（ノート／ユーザー／イベント）、検索語、語がある時のクリア、検索、条件設定を並べています。検索行に別のカプセル枠はありません。対象や条件の選択ボタンを押すと、検索画面自体がナビ側の下端を保って上に伸び、選択肢が画面内に現れます。選択・「戻る」・Esc で元の高さに戻り、元の入力語・結果・条件値を保持します。選択肢が収まらない画面では内側だけをスクロールできます。Tab／矢印キー／Enter／Space で選択できます。条件画面からの Esc は条件を閉じ、次の Esc は検索全体を閉じます。外側タップでも閉じ、フォーカスは検索ボタンに戻ります。

初期語「ガラス」を Enter で検索でき、イベントは空欄でも検索できます。条件設定ではノートの範囲・サーバー／ユーザー・投稿期間、ユーザーのローカル／リモート、イベントの範囲・並び・開催期間を試せます。入力語と UI S の投稿下書きは閉じても残ります。UI S のナビはメニュー・検索・ホーム・通知・Hatask・ウィジェットの順です。ホームを約500ms長押しすると、見本のタイムライン切替が開きます。

結果と条件の適用対象はページ内の固定サンプルです。条件は固定サンプルに合う範囲でのみ反映され、実際の検索サービスとは連動しません。読み込み表示は約350msの演出で、通信・API・保存・投稿・本体への反映は行いません。検索結果行と、検索以外のナビ操作は表示見本です。320〜390px、セーフエリア、`visualViewport` によるキーボード回避、OS の「動きを減らす」に対応します。
