# UI S 投稿フォーム内の確認モック

`index.html` は UI S のガラス投稿フォームで、ノートの「削除」「削除して編集」「リノート解除」を確認する静的モックです。PC では投稿欄を上／下に切り替えられ、モバイルでは下部のドックに固定されます。画面、テーマ、動きの切り替えも上部にあります。

ノート上の操作で投稿欄が確認ビューに変わります。見出しはアイコンを文章の上に置き、文章自体を中央揃えにします。対象ノートのアバター・作者・抜粋、操作ボタンも中央揃えです。確認ビューの操作ボタンはアイコンのみで、キャンセルは閉じるアイコン、確定は削除・削除して編集・リノート解除に応じたアイコンに切り替わります。両ボタンには `title` と `aria-label` があり、確定ボタンは操作ごとに更新されます。押せる範囲は 44px 四方以上で、キーボードフォーカスを表示します。ノート上の起動ボタンと上部の表示設定ボタンの文字ラベルは維持しています。

キャンセルまたは Escape で同じ下書きへ戻ります。確認中はキャンセルに初期フォーカスを置き、Tab を二つの操作ボタン内に閉じ込めます。削除・解除ボタンへ明示的にフォーカスした場合は Enter / Space で操作でき、それ以外の Enter は送信されません。確定時は成功表示だけを出し、ノートや下書きは保存・投稿されません。確認ビュー以外は `inert` と `aria-hidden` で操作対象から外し、表示切替時の高さアニメーションと動き軽減設定に対応しています。

ブラウザ操作はこの作業では未実施です。HTML/CSS/JavaScript は外部依存を持たず、ブランド書体は既存の `packages/frontend/assets/Righteous-Regular.woff2` を参照します。実 API、永続化、投稿処理は含みません。
