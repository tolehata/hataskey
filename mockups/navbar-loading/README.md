# ナビバー外周の読み込みモック

`index.html` をブラウザで開く。試作用で、本番のローディング・API・設定には接続していません。外部通信や依存インストールは不要です。

- 初回は6秒間の読み込みを再生します。「短い読み込み」は100ms、「継続する」は停止するまで続きます。
- PC／スマートフォン、ライト／ダーク、テーマカラー、新着通知、動きの軽減を切り替えて確認できます。タブは選択中のものだけ名前を表示します。
- 光はナビの角丸外周だけを一定速度でめぐります。短い待ち時間では表示せず、表示後は短時間保ってから消えます。連続操作は直前のタイマーを取り消します。
- 動きの軽減時は静かな薄い枠に変わり、OSの設定も尊重します。非表示タブでは周回を停止します。
- Tab／Enter／Spaceで各操作を使えます。読み込み状態は`aria-busy`と読み上げ用の状態表示に反映します。

通常Hataskey UIの`packages/frontend/src/ui/simple.vue`のナビ・レイアウトと、既存`mockups/navbar-pull-refresh`／`mockups/hataskey-new-notes`のSVGや架空投稿を参考にしています。UI Sは対象外です。

表示までの200ms、最低表示500ms、終了時250msのフェードは、このモックでの提案です。本番仕様としては未確定です。ナビ全体が非表示のときに読み込みのため再表示するかどうかも、本番へ接続する際の検討事項です。

既存のLINE Seed JP（`packages/frontend/assets/fonts`）とRighteous（`mockups/ui-s-post-banner`）を相対参照しています。どちらもSIL Open Font License 1.1です。新しいフォント・外部素材は取得していません。モックのコードはAGPL-3.0-onlyです。
