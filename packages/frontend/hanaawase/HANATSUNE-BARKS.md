# 花常 待機時のひとこと(店主の独り言) v1.0

- 正本: HANATSUNE-SPEC.md §3.57 / 状態: **初稿(テーブルリード待ち)**
- 話者は**若菜のみ**。パズル画面の盤面下・一言枠に、手が止まっている間だけ出る
- 表示文 = 主文1本 + 50%の確率で添え文1本(改行連結)

## 文体規律(⚠️追記・改稿する人は必ず読む)

1. **独り言であって接客ではない。** 敬語にしない。ここが若菜の素の声
2. **プレイヤーに語りかけない。** 「がんばって」「すごい」「あと少し」は禁止。画面の外を見ない
3. **「!」を使わない。** 一度も
4. **感情語で埋めない。** 「嬉しい」「寂しい」と書かず、水・光・手触り・音・匂いで書く
5. **匂いの描写は全体で数本まで。** 濫用すると一気に安くなる
6. **説明しない。** 花の豆知識を教える口調にならないこと。彼女は誰にも教えていない
7. 主文・添え文とも**単独で完成した一文**にする。連結を前提にした半端な文を書かない

## 執筆メモ(監修用・ゲームには含めない)

- 主文250 × (添え文45+1) = **11,500通り**。タグ適合フィルタ後の実効も数千通りを確保
- 若菜①(澄まし)が本編で圧倒的に多いのと同じ理屈で、**ここも平熱が基本**。
  盛り上がる行を増やしたくなったら、本編§2.2「説明しない」に戻ること
- **添え文45番の「……。」は意図的**。何も言わない選択肢を1/45で混ぜる
- `rare` 20本のうち 231/233/236/240 は本編の具体的な出来事に紐づく。
  本編未読でも意味が通るが、読了後に意味が増える設計(サブクエと同じ作法)
- ⚠️**テーブルリード必須**。特に添え文は主文とランダムに繋がるので、
  声に出して数十通り試し、繋がりが不自然な組み合わせが出たらタグで制限する
