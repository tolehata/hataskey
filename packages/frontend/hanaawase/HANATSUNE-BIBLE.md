## 1. 世界観総則

- 現代日本とほぼ同じ世界。**獣人が人口の一割ほど、ごく当たり前に暮らしている**。
  作中の誰も獣人であることを特別扱いせず、説明もしない(起源設定は作らない。説明はAI臭のもと)
- 本作の登場範囲では獣人は男性のみ(制作方針。世界設定上の理由付けはしない)
- 語りの原則(全編): 回想シーンを作らない(過去は帳面・会話・物でのみ提示) / 心情を地の文で説明しない /
  「死」「亡くなる」の直接語を使わない / 感嘆符はレンら快活な人物の会話のみ / 泣かせ演出をしない

#### ⚠️語りの原則の適用範囲(2026-07-20 裁定。増補・検品で繰り返し判断が割れたため明文化)
1. **感嘆符を使ってよい人物**: レン / 犬飼 / 辰巳・競り人などの**市場と商店街の売り声** / 子ども /
   **八重（通りの向こうから呼ぶ声・青果店の呼び売りのみ）**。
   ⚠️**若菜・玄・雨宮・地の文では使わない**。
   ⚠️**「祖母の帳面からの引用」に感嘆符が付いている**のは違反ではなく意図的な演出
   (12月本文「感嘆符のついた字は、この帳面で初めて見た」のように、地の文で明示的にメタ言及されているもの)。
   理由: 辰巳の声はBIBLE §5の見本自体が「常サンとこの! 目ぇ肥やしてけ!」であり、
   売り声から感嘆符を取ると人物が死ぬ
2. **「……」1場面3回の数え方**: ⚠️**玄の無言の台詞(`> 玄「……」`)は数に入れない**。
   彼にとって沈黙は台詞そのものであり、他の人物の言い淀みとは別種。
   同様に、**選択肢の分岐で片方しか読まれない行は、1周の実読値で数える**。
   ⚠️**クライマックス例外**: 12月「年の瀬の夜」(種明かしの場面)のみ、この上限を適用しない。
   本章は「説明を足すのではなく間を足す」設計であり(BIBLE §12月構成)、
   ストーブの音・頁をめくる動作・耳の角度・沈黙で運ぶことが本作の感動の核心。
   ⚠️他の場面へこの例外を拡大してはならない。**この1場面だけの許可**
3. **「心情を地の文で説明しない」は `[帳面]` パートには適用しない**。
   帳面は若菜の一人称の記述であり、地の文ではない。⚠️ただし**泣かせ演出をしない**は帳面にも適用する
4. **サブキャストの情報運搬台詞**(八重が常の逸話を語る等)は説明台詞に**当たらない**。
   ⚠️禁止しているのは「実は〜なんです」型の**設定の自己解説**であって、
   人物が人物について語ることは本作の主要な情報経路である(BIBLE §5「機能を一つ持たせる」)
- **間延び禁止の規律**: 1場面1機能(その場面が前に進める糸を必ず1本持つ)。要約の地の文で字数を稼がない。
  会話は「用件+ズレ」(用件だけの会話も、脱線だけの会話も書かない)
- **情景の密度**: 序章(第三稿)を基準とする。情景は場面の頭(空間の確立)と転換部に厚く置き、会話の最中には挟まない。
  感情語で埋めず「場所・光・手触り・音」で埋める。匂いは月1回、比喩は控えめ(序章の上限を超えない)
- **会話が主役**: ビネットは会話劇として書く。各月、会話場面が場面数の過半を占めること。
  地の文のみの場面は序章冒頭と特別な節目に限る(実利: 会話のない場面は立ち絵・表情差分が使えない)。
  サブキャストは立ち絵なし(声+簡易シルエット)で自由に喋らせてよい

## 2. 舞台

### 2.1 入舟町(いりふねちょう)
かつて水運で栄えた川沿いの町。駅から川へ下る「入舟銀座商店街」(アーケードなし、8割が個人店)。
坂を上ると県立の工科大学。花市場(浜市場)は電車で二駅。
商店街の並び(店の左右): 花常 — 青果まるはち — (角) — 喫茶くろまつ — 和菓子霜月堂 — 米屋 — 空き店舗(F-14の種)。

### 2.2 花常(はなつね) — 舞台の中心
- 創業約50年。祖母・三隅常が28歳で開いた。屋号は名前から
- 間口二間。店先に縁台とガラス戸、**トタン庇**(6月「雨の音が丸い」の物理的根拠)。
  奥に作業場(水場・冷蔵ケース)、急な階段の上が住居(若菜の現住居。二階に仏間があるが本文では描写しない)
- 道具: 木の勘定台 / 二十年もののレジ(2月に故障→レンが修理) / 祖母の剪定鋏(柄が飴色。若菜は自分の鋏と使い分けている——**祖母の鋏は枝物のときだけ**という無意識の線引き、10月に自覚する) / 竹箒 / 帳面二冊(常の古帳面・若菜の新帳面) / **白い軽トラ**(常の代から。市場仕入れ用) / **勘定台の奥の丸椅子**(常の定位置。1月にレンの視線が一拍止まる) / 見切り籠**「今日のうちに飾る花」**(1月に若菜が命名)
- くろまつ: カウンターの**空いている隣席**(常の席。玄は言葉にせず、目で若菜を隣にずらした——1月)
- 店の匂い: 水と、切り口の青さと、ストーブの灯油(冬)。匂いの描写は月1回まで(乱発禁止)

### 2.3 浜市場
セリは早朝5時半。競り人・辰巳の掛け声。仲卸「犬飼生花」。買参人の木札。
用語はさらっと使い、註釈をつけない(分からなさも含めて職業世界の実在感)。

### 2.4 坂の上
工科大学(情報工学科)。学生アパート「すみれ荘」203号がレンの部屋。
**坂の下の商店街から、すみれ荘の窓が見える**(F-15)。

## 6. 読書体験の設計(ゲーム統合)

- 各月約2万字を**月内に分散配置**(一括読みにしない):
  `月初帳面 → [n-1後]場面 → [n-2後]場面 → 中間帳面 → [n-3前]場面(ボス月は戦前場面) → [n-3後]大場面 → 月末帳面`
- 1回の読み単位は1,000〜4,500字(スキップ可・花手帖から全文読み返し可)
- ⚠️SPEC §11.2 への修正: ビネットは「月と月の間」ではなく上記の**月内分散**を正とする
- 未読テキストがある状態でも次ステージへ進める(読み物はご褒美であり関所にしない)

## 12.5 分岐設計(選択肢システム)の正本

### 原則
1. **背骨不変**: 12月の種明かしに至る幹は一本。分岐は「どう辿るか」を変え、「何が真実か」を変えない
2. **分岐不変条項**: 伏線台帳(§8)の植・触・回収ビートは**全ルートで必ず発生**する。分岐はビートの順序・場所・色を変えてよいが、消してはならない
3. **善悪をつけない**: どの選択肢も「正解」ではない。頼るのも、自分でやるのも、聞くのも、待つのも、それぞれの若菜
4. **帳面が分岐の記録**: 選択の結果は帳面の文面に現れる。プレイヤーごとに「自分の一年の帳面」が出来上がる——これが本作の分岐の見せ方の核
5. エンディングは一つ。**終章の帳面がモジュール組立**(選択の蓄積で行が入れ替わる)で、全員少しずつ違う一頁になる

### スタンス軸(隠しパラメータ・2軸のみ)
| 軸 | 増える選択 | 効果 |
|---|---|---|
| **縁(えん)** | 人を頼る・受け入れる | 高: 町の人々が場面に加勢する変奏が増える / 低: 若菜の独立独歩の色が濃くなる |
| **問い** | 謎に踏み込む | 高: 12月の種明かしが「若菜が帳面を先に見せる」開幕 / 低: 「レンから語り出す」開幕(内容は同一、順序と色が変わる) |

### 記法(本文ファイル共通)
```
◆選択 B-xx「題」(軸: 縁/問い/なし)
→ A. 選択肢文
→ B. 選択肢文
【A】(A分岐テキスト)
【B】(B分岐テキスト)
【合流】(共通テキスト)
```
帳面の可変行: `{B-xx=A: 文面}` / `{B-xx=B: 文面}` / `{縁高: 文面}` 等
補則: **【合流】が無い分岐は場面末尾まで続く**。場面途中の可変ブロックは `【B-xx=A】/【B-xx=B】/【合流】` でも書ける(選択自体は過去の月のもの)

### ストーリーのみモード(読み物モード)
- ホームの二導線は **「花仕事(はなしごと)」/「帳面(ちょうめん)」**。
  - **花仕事** = 通常プレイ(盤面と共に一年を進める)。遊ぶこと=花を扱う仕事をすること
    (※「商い」案は売買・課金要素との誤読の恐れがあり不採用)
  - **帳面** = パズルを自動スキップして物語と選択肢だけを進める。読むこと=若菜の帳面を読むこと
  (進行データは共通。どちらのモードでも選択は一度きり、花手帖に記録)
- 花手帖「通し読み」: 体験済みテキストを縦書き連続表示。**クリア済みの月は分岐の切替可**(未選択側も読める)
- 選択肢は「帳面」モードでも必ず提示する(読むだけの人にも「自分の帳面」を作らせる)
- **UI語彙基準**: メニュー・ボタン文言は漢語基調でシックに。ひらがなポップ(「あそぶ」「〜しよう!」)は用いない。
  例: つづきから→「続きから」/ デイリー→「今日の盤面」(既定) / サブクエ→「頼まれごと帖」(既定) / 設定→「設え(しつらえ)」は凝りすぎのため「設定」のまま

## 13. 執筆工程(厳守)

1. 執筆は**1回の作業=1ヶ月分**(約2万字)。順序は序章+1月→2月→…→12月+終章
2. 各月の執筆前に本書§8・§10を読み、執筆後に台帳の「植/触/回収」実績を更新する
3. 各月完成ごとに**音読テーブルリード**(人間監修)→修正→確定。確定前に次の月へ進まない
4. 文字数は19,000〜21,000字。超過しそうな場合は場面を削る(薄める・要約するのは禁止)
5. 完成本文は `HANATSUNE-STORY-01.md` 〜 `-12.md`(+ `-00.md` 序章 / `-13.md` 終章)として保存
6. サブクエ本文は `HANATSUNE-SIDE-01.md` 〜(月ごとにまとめて1ファイル可)。台帳「触」の実績も§8に記録する
