# Codex 画像生成依頼（本編背景の追加）

Claude（設計・実装担当）→ Codex（画像生成担当）への依頼書。花常の没入感を上げるため背景を増やす。
方針は「**共有変異ライブラリ（場所×時間帯×天候）＋月別ヒーロー＋イベント背景**」。各月が約10種の背景を出す状態を、ユニーク120枚でなく賢い再利用で作る。

⚠️正本: `HANATSUNE-SPEC.md` §12.75（背景構図）・§12.15（生成実務）・§12.5（CSS代替の線引き）・§9.7.55（BgId）。本書は下位文書。矛盾は本書でなく `HANATSUNE-WORKLOG.md`「仕様への申し送り」に書く。

## 0. 着手前（飛ばさない）
1. §12.15 を読む（寸法は**アスペクト比 16:9** で指示・ピクセル値は効かない／利用枠の消費が速い＝**1枚ずつ**）。
2. §12.75 を読む（構図規律＝中央下40%に主題を置かない・人物を描かない・**明度を最初から落とす**）。
3. §12.5 を確認（`street`/`indoor_other`/汎用 `outskirt` は CSS。⚠️**PNGを作らない**）。
4. ⚠️背景は **-i（参照画像）を渡さない**（キャラ画風の引きずり防止）。
5. 生成順は §4 の P1→P2→P3。⚠️**1枚生成するごとに WORKLOG の進捗表を更新**する。
6. ⚠️ヒーロー4枚（`market_dawn`/`naito_field_night`/`sakanoue`/`shotengai_night`）は本来 §12.75.4 でCSS指定の場所。**署名場面としてPNGへ限定昇格**する。着手前に WORKLOG「仕様への申し送り」に昇格を記録済みであること（Claude記録済み）。

## 1. 共通の先頭ブロック（全背景プロンプトの先頭に必ず貼る）
```
【画風（厳守）】色数を抑えた絵本調の背景イラスト。線は細く面で描く。キャラほど強くデフォルメしない。
パレットは 墨#2b2620／生成り#f4efe3／朱#c4383d／藍#2d4a73／金#c9a04e／苔緑#5a7a52 を基調。
質感はフラット〜ごくわずかなグラデ。昭和の日本の下町「入舟町」の空気。生活感・のどか。
【禁止】原色・蛍光色／写真的レンダリング／強い光芒・レンズフレア・光の粒／観光ポスターの華やかさ／
人物（遠くの小さな人影シルエットのみ可）／実在の店名・企業名・読める看板文字／文字・ロゴの描き込み。
【⚠️構図（最重要）】この背景の上に会話枠・カード・ボタン・立ち絵が必ず重なる。
・中央下40%＝主題を置かない。暗く平坦に（会話枠が来る）
・左右の下端＝細かい描き込みを置かない（立ち絵が立つ）
・上部30%＝ここに主題（空・軒・遠景）を置く
・中央上＝強い模様を置かない（ロゴが乗る）
・消失点と視線誘導を中央に集めない
・⚠️画面全体の明度を最初から落として描く（あとから暗くしない。最初から引っ込んだ絵に）
【比】16:9
```

## 3. CSS維持（PNGを作らない・§12.5）
`street`（通りを歩く通過場面）／`indoor_other`（会話主体・くろまつ店内・部室）／汎用 `outskirt`（川べり等）は**CSS環境表現のまま**。ボス天候（春荒・五月雨・野分・大霜）も**盤面に transform/opacity オーバーレイを重ねる方式が正**。背景PNGに嵐を描かない。

- **イベント背景**: 本編P1〜P2の後。1本2〜3枚（差し色1色差し替えで流用可）。

## 5. 保存・後処理
- 保存: `packages/frontend/assets/hanaawase/bg/<id>.png`（配信 `/client-assets/hanaawase/bg/<id>.png`）。比は必ず **16:9**。
- **1枚 400KB 以内**に減色（超えたら減色して等倍再確認）。
- ⚠️生成後、**仮の黒半透明矩形を中央下に重ねて文字が読めるか確認**（§12.75）。
- `~/.codex/generated_images/` をリポジトリに混入させない。ディレクトリ操作は PowerShell（UNCで Bash のファイル作成が通らない＝既知地雷）。

## 6. よくある失敗
- 中央に主題→会話枠で潰れる（構図ブロックを毎回貼り、生成後に半透明矩形で確認）。
- 明るく綺麗すぎて立ち絵が沈む（「最初から明度を落とす」「観光ポスターにしない」）。
- 看板に読める文字（色面と抽象筆致で潰す、等倍で文字を探す）。
- 市場/畑をCSS対象と混同（本書のヒーロー4枚のみPNG。street等はCSSのまま）。
