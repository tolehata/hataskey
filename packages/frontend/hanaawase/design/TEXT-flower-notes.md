## 1. 書き手の規律（§3を読む前に）

- 話者は**若菜**。店先で客に説明する言葉。ですます。⚠️感嘆符は使わない
- ⚠️**本文の中で他の花の名前を出さない**（未取得の月の花名は、それ自体が先の月の内容になる）
- ⚠️**花言葉・学名・書籍の引き写しを一切置かない**。書いたのは水揚げ・日保ち・選び方・
  どんな客がどんな用で買うか——「店の人が本当に知っていること」だけ
- ⚠️薬効・効能は書かない。紫陽花の葉の注意は「口に入れない」までで止める（六月）
- ⚠️表示側は `word-break: keep-all`。**1行は句点2つまで**を目安に短く切ってある

## 4. 特別な札（実装と突き合わせ済み）

### 4.1 検証の根拠

`engine.ts` の下記を読んで数値・条件を確かめた。

| 関数 | 行 | 読み取った規則 |
|---|---|---|
| `specialFor` | 185-203 | ①縦横の列が交わっていれば長さに関係なく `mari` ②交わりなしで最長5以上なら `tsuki` ③最長ちょうど4なら `tanzaku`、`axis` は**揃えた向きの直角**（`direction === "row"` なら `"column"`） |
| `specialTargets` | 223-260 | 単独起爆の消去範囲 |
| `line` | 205-210 | `width` 既定1 → `axis="row"` で**その行すべて**、`"column"` で**その列すべて**。`width=3` で3列ぶんの帯 |
| `square` | 211-216 | `radius=1` → 3×3＝**9マス**（自分＋周囲8）／`radius=2` → 5×5＝**25マス** |
| `color` | 217-220 | 盤上の同じ花**すべて** |

単独起爆の内訳（`specialTargets` 228-230）:
- `tanzaku` → `line(board, a, first.axis)` ＝**行または列を丸ごと1本**
- `mari` → `square(board, a, 1)` ＝**3×3の9マス**
- `tsuki` → `color(board, second.flower)` ＝**入れ替えた隣の花と同じ花を全部**
  （隣が特殊札でないとき。`second` が無い場合は自分1マスのみ）

⚠️**現行文面との差**: `tsuki` は「五枚」ではなく **`longest >= 5`（五枚以上）**。
`tanzaku` の払う向きは「通った筋」ではなく **揃えた向きと直角**。この2点を直した。

### 4.2 そのまま流し込むコード
