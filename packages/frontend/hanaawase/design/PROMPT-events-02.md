## お願い① イベントの「様式」を整理する

今後イベントを何本も追加します。そのたびにデザインを一から作らずに済むよう、
**「イベントごとに差し替わる部分」と「毎回共通の部分」を分離**してください。

### 差し替わるのは、この4つだけにしたい
| # | 要素 | 第1回での値 |
|---|---|---|
| 1 | **差し色**（`--evt`）1色 | **藤 `#8e7cb0`** |
| 2 | **装飾モチーフ**（イベントホーム上部を漂う小さな要素） | **紙片**（後述） |
| 3 | **ポイントの意匠**（SVGアイコン1つ） | **「町の憶え書き」＝小さな紙片** |
| 4 | **ロゴ**（題字＋副題＋印章の中身） | 後述 |

⚠️前回作っていただいた「提灯の列」と「金魚すくいの札」は、**第1回では使いません**
（夜市は仮のテーマでした）。ただし**様式の実例として残しておきたい**ので、
「差し色・モチーフ・ポイント意匠を差し替えると、こう変わる」という**対比が分かる見せ方**にしてもらえると助かります。

### 装飾モチーフ（第1回）
上部を **紙片が数枚、ゆっくり流れる**。前回の提灯と同じ扱い（`opacity` と `transform` のみ、控えめ）。
- 紙片は**罫の入った小さな紙**。⚠️文字は書かない（読めない線1〜2本まで）
- ⚠️舞い散らせすぎない。**同時に5枚まで**、ゆっくり

## お願い② 第1回イベントの実物

### 基本情報
- **イベント名：孫の居ぬ間になんとやら**
- 副題：**「探しものは、みつからないほうがいい」**
- 差し色：**藤 `#8e7cb0`**
- 季節：**初夏の昼**（前回の夜市とは逆に、明るく・のどか）

### あらすじ（デザインの雰囲気の参考に。画面に文章は載せません）
「きよばあ」という老女が「孫を探している」と言って花屋を訪れます。
一緒に町を回るうち、彼女が行く先々で楽しそうに油を売っていることに気づく——
孫は普通に出かけているだけで、「探している」は**一人で町を歩くための口実**でした。
明るく、少しおかしく、最後に少しだけしみじみする話です。⚠️お涙頂戴にはしません。

### ⚠️ロゴ（ここが今回いちばんの相談）
題字が **「孫の居ぬ間になんとやら」＝11文字**あり、
前回いただいた型（4〜6文字想定・横一列＋罫）では**収まりません**。

次のどちらか、または両方を試してください:
- **2行に割る**（例：「孫の居ぬ間に」／「なんとやら」）。
  ⚠️2行目を**下げて字下げ**すると軽妙さが出ると思いますが、判断はお任せします
- **級数を落として1行**（ただし小さくなりすぎると弱い）

条件:
- **明朝**。⚠️題名がとぼけた言い回しなので、**堅くなりすぎない**字組みに
- **印章**の中身は**桔梗**（藤色の花）にしてください。罫は `--evt`
- 副題「探しものは、みつからないほうがいい」を小さくゴシックで
- ⚠️**今後もっと長い/短い題名が来ます。** 何文字でも破綻しない組み方の指針を、
  短くメモで添えてもらえると助かります

## お願い③ 背景のセーフゾーン表示

背景は**これから画像生成で作ります**。前回は `EVENT BG ART` のプレースホルダでしたが、
**絵を作る人が構図を誤らないためのガイド**が欲しいです。

プレースホルダの中に、次を薄く重ねてください（開発用パネルで**表示/非表示を切り替え可能**に）:
- **中央下 40%** … 「情報が乗る／主題を置かない」の帯
- **左右の下端**（PC 170×400 / モバイル 120×300）… 「立ち絵が立つ」の枠
- **中央上** … 「ロゴが乗る」の枠
- **上部 30%** … 「ここに主題を置く」の帯

⚠️これは**開発用の目安表示**で、製品画面には出ません。そうと分かる見た目（細い破線＋小さな注記）で。

## ⚠️お願い④ 開催時間の表記を1語に統一してください（前回からの変更）

前回いただいた「**会期 のこり 6日**」の**静かな書き方はそのまま**ですが、
**見出しの語を「開催時間」に統一**しました。⚠️言い換えないでください。

| 状態 | この文字列で |
|---|---|
| 開催前 | `開催時間 8月1日から` |
| のこり2日以上 | `開催時間 のこり 6日` |
| 最終日 | `開催時間 本日まで` |
| 終了後 | `開催時間 終了しました` |

- ⚠️使わない語: **会期／開催期間／開催時期／残り期間／あと◯日（単独）／近日開催／
  まもなく／終了間近／終了済み**
- ⚠️**「のこり 0日」を出しません**。最終日は「本日まで」に切り替わります
- ⚠️数字だけを大きくするのは構いませんが、**赤字・点滅・警告色にしない**でください（`--sub` のまま）
- ⚠️「開催時間」は単独で置くと営業時間のように読めるので、**必ずラベル＋値の対**で出してください

**告知・イベントの扉**では、次の完全表記を使います（3行）。
```
開催時間
2026年8月1日(土) 0:00 から
2026年8月18日(火) 0:00 まで（日本標準時）
```
- ⚠️タイムゾーンは**日本語で「日本標準時」**と書きます。⚠️`JST` や `+09:00` と書かないでください
- この3行が入る**静かな置き場所**を、イベントホームか扉のどこかに用意してください

**アーカイブ一覧**は季節の表記（「初夏」）のままにしてください。
⚠️一覧に日付を並べず、扉を開いたときだけ上の3行を「**これまでの開催時間**」として出します。
