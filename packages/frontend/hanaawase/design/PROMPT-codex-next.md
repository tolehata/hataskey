## 1. ⚠️名鑑：未登場のスチルが最初から全部見える（本物のバグ）

**原因は特定済み。** `Gallery.vue:215`

```ts
return entry.stills.filter((still) => shown(stillPath(entry.id, still.file)));
```

`shown()` は `const shown = (src) => !failed.value.has(src)`＝**「画像の読み込みに失敗していないか」だけ**。⚠️**物語の進行を一切見ていない**ので、始めたばかりでも全スチルが見える。

### 直しかた
- ⚠️`gallery-data.ts` の `GalleryStill` に**解放条件**を足す（例：`since: number`＝その月に到達したら見える／または `vignetteId`）。⚠️**どのスチルが何月のものかの対応表がデータに無い**ので、⚠️**本文を読んで決める必要がある**（判断が要るなら一覧を出して依頼元に確認すること）
- 判定は既存の `progress`（`stars` / `vignettesSeen`）だけで完結させる。⚠️新しい保存キーを増やさない
- ⚠️**未解放は「隠す」ではなく「まだ見ていない」と分かる形**にする（カードの `locked` と同じ作法が既にある）
- ⚠️テストを足すこと（未解放の進行で `visibleStills` が0件、到達後に増える）

## 5. ⚠️原因が特定できていない2件（⚠️推測で直さないこと）

### 5.1 花手帖の花が右に寄る
`.dex-grid` は `repeat(4, minmax(0, 1fr))` で、右寄せの指定も `direction: rtl` も**無い**。⚠️ソースからは原因が見つからなかった。⚠️**まず再現条件（窓幅・UIの種類）を掴んでから**直すこと。

### 5.2 物語で会話枠の高さが行ごとにばらつく／スクロールが要る
⚠️器の高さは `min-height: max(360px, 125cqw)`、広いとき `@container (min-width: 720px)` で `77cqw`。
⚠️**`vh` を使わない**（画面の高さ基準なので小窓ではみ出す）。⚠️**`@media` ではなく `@container`**（画面幅で切り替えると小窓で潰れる）。拠り所は `index.vue` の `.story-shell { container-type: inline-size }`。⚠️**外さないこと**。
⚠️**器の高さを中身で決めない**（立ち絵の有無で背が跳ねる。実際に起きた）。
