# 花常 文体技法書 — せつなさの作り方（2026-07-25 制定）

⚠️**この作品の余韻は足し算で増えない。削ると増える。**
本書は本文の実測（序章〜終章）から逆算した技法書。⚠️正本（BIBLE/STORY）は書き換えていない。改稿時の判断基準として使う。

## 0. この作品の背骨（磨くとき必ず確認する2本）
1. **若菜が一年かけて上達しなかったこと**（枝の"音"が聞こえない）
2. **帳面が数字から名前に変わったこと**

⚠️どちらにも触れていない一文は、削っても作品は減らない。

---

## 1. 効いている型（本作の発明）

### ① 数の詩学 — 感情を書かず、数える。数が壊れる瞬間が頂点
- 「一月の頁の名前は、四つ。五月は三十九。**十二月は、数えるのをやめた**。」← 本作最高の一節
- 「残りは、あと三杯ぶんだった。」← 期待を在庫で書く発明
- 「今日はもう四回読んでいる。」← 執着を回数で書く

⚠️**数を出したら意味を説明しない**。説明した瞬間に数は情報へ落ちる。

### ② 物に語らせる（そして通訳しない）
- 「椅子の脚が、床のいつもの窪みに、かちりと嵌まった。」
- レン「使い込んだやつは、その人の握りに合わせて減ってるんですよ」← **他人の口**だから通訳にならない

⚠️物が語ったら地の文は黙る。**本作の最頻の失点は「物に語らせた直後に自分で通訳する」**。

### ③ 泣かせずに泣く（模範解答）
> 声の途中が、少し濡れていた。**若菜は、聞こえなかったことにした。**

⚠️感情語ゼロ・涙ゼロ。**観測者が観測をやめ、読者だけが取り残される**。以後この型のみ使用する。

### ④ 不在を「しない動作」で書く
- 「勘定台の奥に、丸椅子がひとつある。**二人とも、そこには座らなかった**。」

### ⑤ 時間の跳躍 — 待った時間を書かない
- 「**次の雨は、四日後に降った。**」⚠️着地には必ず具体の変化を一つだけ置く。

### ⑥ 一文に時間を二つ入れる（★せつなさの主因）
- 「その下の層は、たぶん、祖母の手が**五十年**当てた色だ」／「**習う前に**、写していた」
- 「今」と「今でない時」が同居した瞬間、読者は時間の落差に落ちる。

## 2. 削るべき型（緩みの検出）

| 型 | 症状 | 処方 |
|---|---|---|
| A | `〜ということは、〜ということだった` | ほぼ全部削れる。前半だけで成立している |
| B | 「一月の『よかった』が、十一ヶ月かかって、意味になった」 | ⚠️**伏線回収の作者アナウンス**。読者から気づく権利を奪う。全削除 |
| C | 「もうすぐ全部が来る。そういう夜の匂いがしていた」 | 次章の予告＝**この場面の余韻を売り渡す**。削除 |
| D | `妙に` `不思議と` `やけに` `どこか` | 作者の評価が漏れている。削る |
| E | 同じ内容の三連 | **最後の一文だけが本物**。前二文は助走 |
| F | 場面末で種明かし | 不可解さは不可解なまま残す |
| G | 「いい音が鳴っていた」 | 評価語。⚠️この場面の主題（善し悪しはまだ分からない）と矛盾 |
| H | 帳面のアフォリズム化 | 具体三つだけ残し、頭の宣言と尻の格言を落とす |
| I | 要約の前置き | 後続の名文の邪魔をしている |

## 3. 場面の閉じ方（原則：今より一文早く切る）

**維持すべき模範3つ**
- 「温度計の赤い線は、夜のあいだ、ほとんど動かなかった。」← **場面末の基準値**（主語が物・動詞が否定形）
- 「長靴の音が遠ざかって、通りがまた静かになった。」← 他人の退場音で閉じる
- 「残りは、あと三杯ぶんだった。」← 所有の残量で閉じる

**⚠️決意・宣言で場面を閉じない**（「〜しようと思った」は余韻の反対物）。

---

## 4. 禁じ手（必ず「代わりに何をするか」と対で覚える）

| やらない | 代わりに |
|---|---|
| 死・病名・余命・葬式・墓前の描写 | 場所と物で書く（「白い部屋」「花が、目盛りだったんですね」） |
| 涙の描写（泣く/涙/嗚咽） | 声の質を書き、観測者に観測をやめさせる |
| 回想シーン | 帳面の一行／物の減り／床の窪み／他人の伝聞 |
| BGM・SEに感情を担当させる | 音を**名詞で本文に書く**。演出は本文の後追い |
| 感情語で埋める | 場所・光・手触り・音・**数** |
| 不在の主役をもう一度殺す（命日・遺品整理の場面） | 不在は増やせない。増やせるのは**残っている物の量**だけ |
| 「実は〜だったんです」型の説明台詞 | 物を二つ置く（玄の豆「浅いのと、深いの」＝一言も説明せず全部言った） |
| 花の擬人化（花が寂しそう） | 花は**生理**で書く（水が下がる／腰が抜ける／蜜を拭く）⚠️作中で即座に否定する呼吸を維持 |
| 大団円（全伏線を閉じる） | F-14は開いたまま終える。⚠️**開いたまま終えるのは設計**。減らさない |
| 主人公が完成する（音が聞こえるようになる） | 未達を未達のまま書き、一度だけ触れて済ませる |
| 伏線回収を作者が申告する | 読者に気づかせる。地の文は物へ戻る |
| 比喩の連打・匂いの乱発 | 比喩は序章が上限。**匂いは月1回**（⚠️12月は現状3回で超過） |

## 5. 心に残る一文の条件（6つのうち4つ以上を満たすもの）
1. **主語が人でなく、物・音・光・数**
2. **検算できる**（数・寸法・時刻・回数がある）⚠️「たくさん」「しばらく」は検算できない
3. **感情語をひとつも含まない**
4. **時間を二つ含む**（★これがせつなさの発生源）
5. **一拍遅れて意味が来る**（即座に感動させる文は二度読むと薄い）
6. **店の外に持ち出すと意味が壊れる**（通じないことが強度）

### ⚠️「名言」を量産しないための実務ルール
- **ポスター・テスト**：切り出してポスターにできる文は、外すか値引きする
- **格言には必ず値引きを後置**：「いい言葉ですね」→「意味は、まだ半分しか分かりません」← この呼吸を毎回入れる
- **常の語録は増やさない**（現在10本が上限）。⚠️10本しかないから一本が重い。新しい言葉が要るなら**辰巳・八重・内藤に言わせる**
- **一般化の主語**（客は／人は／花屋は）は**1章2回まで**
- **名言の直後に、誰かが茶々を入れるか手が動く**
- ⚠️**レンに解釈を語らせない**（「センセイが言いたかったのは、たぶん〜」は絶対に書かない）。彼の機能は事実の提供であって解釈ではない

## 6. 検品チェックリスト（1場面ごとに機械的に回す）
1. `〜ということは` `〜ということだった` `〜のである` → その文ごと削れないか
2. `妙に` `不思議と` `やけに` `どこか` → 削る
3. **場面末の最後の一文を削って読み直す**。良くなったら確定
4. 伏線に言及するメタ文（「〜の続きが、そこにあった」型）→ 全削除
5. 比喩の数を数える。1場面2つ以上なら1つに
6. 匂いを月単位で数える。**2回以上なら超過**
7. 「……」を数える（玄の無言は除く）。1場面4回以上なら削る
8. 感嘆符の話者確認。⚠️若菜・玄・雨宮・地の文にあったら即削除
9. 一般化の主語を章単位で数える。3回以上なら具体へ戻す
10. **数字を含む文が1場面に1つ以上あるか**（無ければその場面は薄い）

## 7. 改稿の作業順
1. **削るだけで効く**（低リスク・高効果）— §2のA〜I型を削除。新しい文をほぼ書かずに余韻密度が上がる
2. **規律の再検品**（機械作業）— §6を全13ファイルに1回通す。⚠️**12月の匂い3回**は確定の規律違反
3. **帳面の声の研ぎ直し**（要執筆）— 一般化の主語を配給制に、最終行を翌日の予定で終わらせる
