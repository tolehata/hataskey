⚠️提案はすべて「泣かせ演出をしない／心情を地の文で説明しない／**新しい不幸（悲劇・病気・死）を足さない**」の枠内。

## 1. 感情曲線の実測

**形**: 1〜3月＝急勾配の立ち上がり → **4〜5月＝谷** → 6〜9月＝安定した高原 → 10月＝主題の頂点だが関係は停滞 → 11月＝溜め → 12月＝解放

### ⚠️薄い月・間延びしている月（名指し）
| 月 | 症状 |
|---|---|
| **4月** | **全12ヶ月で最も薄い**。主線を動かすビートが F-15植だけで、しかもそれが「意図的に何も起こさない」設計。初任給は単体では見事だが**若菜もレンも変わらない**。⚠️12月の帳面が「四月の、桜の売れ残りを始末した夜。鉛筆を持って、開いて、閉じた」と**4月本文に存在しない出来事を回想している**＝最良の素材が後出しで捨てられている |
| **5月** | 山が月末2行に集中し、中盤4,500字が平坦。母の日当日は情報密度は高いが**感情の勾配がない**（行列・筍・柏餅…と横に並ぶだけ） |
| **7月前半** | 「犬と狼」＋「空き店舗の噂」＝5,600字が将来のための装置設置で、7月内での勾配を持たない |
| **10月** | 質は最高だが「受け売りが私の言葉になる」が**四度**出る（主題の反復過多）。かつ**レンがこの月だけ完全に観察者**で、二人の関係が一ミリも動かない |
| **6月B分岐** | B-11で「言葉だけ伝える」を選ぶと6月の第二の山が消え、サブクエに逃げる。**サブクエ未プレイの読者は山を一つ失う** |

## 2. この作品の「泣かせ方」の型（言語化）
1. **意味の後払い** — 所作を先に置き、意味を数ヶ月後に払う（両手／新聞紙の斜め一巻き／竹箒／丸椅子）。一度目は情緒、二度目に意味で泣く
2. **数量への置換** — 名前の行数（1月2つ→3月4つ→8月7つ→11月31→**12月「数えるのをやめた」**）／豆「あと三杯ぶん」／灰色の紙十七枚。**数えられるものしか書かないから、読者が意味を足す余地が生まれる**
3. **不在の器** — 常は「空いている隣席」「丸椅子」「白い頁」「予備の簾一枚」という**空白の物**として在る。埋めない
4. **ピークからの離脱** — 最高点の直後に必ず実務か軽口（「ろうそく、もう一本」「じゃ、おそろいっすね」）。**この逃げが、読者に泣く場所を空ける**
5. **問いで章を閉じる** — 「よかったって、何がだろう」「筋がいいって、誰のことだろう」
6. **常を第三者の口で、欠点ごと出す** — 碁に負けると花に当たる／値切りは町一番／写真を撮らせない。**聖人化しないから実在し、実在するから不在が痛む**

## 3. ⚠️取りこぼされている鉱脈（5本）
1. **常の「顔」が残っていないこと** — 八重「撮ろうとすると鋏を持って逃げるの」が**一度も派生していない**。祖母の顔を思い出しにくくなっていく一年は書かれていない。12月の「白い頁」と対になるべき最大の空白が未使用
2. **レンの「一年間の遠回り」に伏線がゼロ** — 12月の告白「十五分よけいにかかるんですけど、そっちのほうが早く帰れる気がしてました」は本作で最も痛い情報なのに、**1〜11月に痕跡が一つもない**
3. **雨宮の「不在の3ヶ月」** — 6・8・12月の3点しかなく9〜11月が空白。「雨の日にだけ来る人」なのに9〜11月に雨が降らなかったことになっている。**来なくなった期間の不安**という無料のせつなさが未使用
4. **若菜の母（花が苦手）** — 8月に一度出て以後消滅。**常と娘のあいだの一世代の断絶**は継承テーマの影そのものなのに12月にも終章にも戻らない
5. **玄の碁盤** — 「碁盤の蓋の縁が、そこだけ手垢で光っている」。碁敵は常。**この盤は最後まで一度も開かない**

## 4. 磨き上げの具体提案

### ★最優先（効果順）
1. **⑨ レンの遠回りの痕跡を11月までに一つ植える** — 川向こうの橋のたもとにレンの自転車を見かける（声はかけない／理由は書かない）。または9月の堂本電話を「橋のとこ、通れます?」に変える。⚠️**12月の重さに対する唯一の構造的欠損**
2. **(a) 竹箒／レジの師弟関係を一度だけ逆流させる** — 2月に「叩くのは祖母がやっていた直し方」とある。台詞一つ（「あれ、最初は俺がやったんすよ。そしたらセンセイが真似して」）で**師弟の一方通行が折り返り、常が受け取る側になった瞬間が生まれる**
3. **(c) 若菜側の一行の告白** — 現状レンは全部話すのに若菜は無言。「二月から、聞きたかったんです」→「聞かなかったっすね」→「聞くと、あなたの一輪の意味が、変わる気がして」。⚠️**これで12月が二人ぶんの告白になる**
4. **① 4月に「鉛筆を持って、開いて、閉じた」を理由なしで置く**（追加3行以内）— 12月がその一行の再訪になり、**8ヶ月越しの回収に化ける**
5. **⑥ 雨宮の不在を一行**（9〜11月）— 「今月は、雨が三度降った。雨の日の人は、来なかった。」理由は書かない。⚠️病気を足すのではなく既にある匂いを**不在という形でだけ**使う。コストゼロで最大級
6. **(b) 説明の二行を削る** — 「七月の、言い掛けの続きが、そこにあった」「一月の『よかった』が、十一ヶ月かかって、意味になった」。⚠️**抑制で通してきた作品が、いちばん大事な場面で読者を信用していない**
7. **⑮ 「一輪の記録」欄を12ヶ月そろえる** — 1・2・4・6・9月の帳面に同じ位置の一行を追加。読者が目で12行を数えられる

### その他
- **② 4月のF-15を「花のない窓」に** — 二階の右から二番目だけカーテンが開いて窓辺に何もない。11月の「色があった」が**無→有の差分**になる
- **③ 5月の狂騒に、客の来ない十分間**（丸椅子を一度見る）。忙しさは勾配を作らないが**忙しさの中の空白は作る**
- **④ 芍薬のツケを「物」にする** — レンが伝票の裏に書いて引き出しに入れる
- **⑤ 灰色の紙の残枚数を追う**（6月17枚→8月→12月）。**彼女が来ない月は減らない**
- **⑦ 7月B-14のB側にも「言葉の予約」を置く**（分岐の張力差を埋める）
- **⑧ 10月の鋏の場面に、レンの握り方が若菜と同じだった一行**（若菜は気づかない）。10月の関係停滞がこれ一行で解ける
- **⑩ 11月の付箋の剥がし跡** — 12月に開くとその頁だけ紙が毛羽立っている（半行）
- **⑪ 12月に常の「顔」を一度だけ** — 「センセイの写真、ないんすか」「ありません」「……ですよね」。それ以上書かない
- **⑫ 丸椅子の向きを完済** — 1月「どの向きなのかは、知らないままだった」→12月「向きは、この向きだった」（半行）
- **⑬ 碁盤の蓋を一度だけ外す** — 石が二つだけ置いてある。誰の手番かは書かない。玄は何も言わない（新規設定ゼロ）
- **⑭ 終章で母を一行** — 「大阪から電話。青は、まだ飾ってあるらしい」。和解ではなく**一段の緩みだけ**

### 削る
- 10月末「言葉は回る。結びも回る。店も、たぶん、そうやって回っていく。」← 作者の要約
- 8月末「それなら、この店は、ずいぶんたくさんの人の帰る場所の、裏方をしていることになる。」← 結論を出しすぎ
- 大晦日「祖母は耳で買い、私は帳面で買う。」← 辰巳の「焦んな」だけ残すほうが痛い

## 5. 12月の種明かし

### 効いている（触らない）
- **順序が正しい**：レンが語る→2月の頁→11月の頁→「約束、破ったんです」→**未来の約束に付け替える**→「坂の下から見ますから」で若菜の秘密も暴かれる
- **告白が一方通行になっていない**：「二階の、右から二番目」で**見られていた側が、見ていた側になる**。ここで場が対等に戻り湿度が抜ける
- **F-05の解毒**：「珈琲が熱いだけです」でロマンスを名指しせず感情を一度だけ可視化して引っ込める
- 大晦日「センセイ、と書いてみて、消した」「呼び名が二つあるだけ、その人は、少しだけ長く、この店にいる」← **触らない**

### ⚠️弱いところ
- **(d) 「聖夜の洋花」(2,200字)が勾配を殺している** — 種明かしの二つ手前に機能の弱い場面が入る。松市の直後へ移動して「祭りの月」にまとめるか、削って年の瀬の夜に字数を回す
- **(e) 【問い低】ルートの開幕が弱い** — 若菜の手が引き出しにかかったまま止まっていた、を半行
- **(f) 大晦日帳面に名句が3〜4本並走** — 「三杯ぶん」「センセイと書いて消した」「4つ→39→数えるのをやめた」の**三本に絞る**と一本ずつが立つ
