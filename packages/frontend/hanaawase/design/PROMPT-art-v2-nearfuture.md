# Codex 画像生成依頼 v2（近未来・大量生成）

Claude（設計・実装）→ Codex（画像生成）への依頼書。**利用枠のリセット期間中に一気に素材を積む**のが目的。

## ⚠️0. 最重要：画風の方針転換（2026-07-25 利用者裁定）

**背景の画風を「近未来チックかつ明るい・ワクワクする」へ全面変更する。**

- これは `HANATSUNE-SPEC.md §12.75.1`（昭和の商店街・絵本調・原色/蛍光禁止）**からの意図的な転換**であり、利用者が既存正本との衝突を承知のうえで決定した。
- ⚠️**SPEC本体は書き換えていない**。齟齬は `HANATSUNE-WORKLOG.md`「仕様への申し送り」に記録済み。**本書が背景画風の最新の正本**とする。
- ⚠️**キャラクターの造形・服装・画風（§12.7）は変更しない**。若菜＝白い椿の髪留め／レン＝黒×青ヘッドホン等の不変条件は**そのまま厳守**。変わるのは**背景と、背景に載る光や小物の質感**だけ。

### 新・背景の画風定義（全背景に適用）
```
【画風（厳守）】
明るく開けた近未来の街。清潔でやわらかい未来感。フラット〜わずかなグラデのイラスト。
やさしい発光（ネオンサインではなくパネルや行灯型の面光源）、浮遊する光の粒はごく控えめ。
ガラス・白い construction・淡い金属・植物との共生（緑化された街）。空は広く高い。
「明日が楽しみになる」トーン。生活感は残す（人の営みが見える街）。
【色】
基調は 生成り#f4efe3／白／淡いミント#bfe3d4／空色#a9cfe8／淡い金#e3c98a／墨#2b2620 を軸に、
差し色は各月の花の色を1色だけ。⚠️どぎつい原色・蛍光・サイバーパンクの紫ピンク一色は使わない。
【禁止】
サイバーパンク（暗い・雨・毒々しいネオン）／ディストピア／機械的で冷たい印象／
写真的レンダリング・強い光芒・レンズフレア／人物（遠景の小さなシルエットのみ可）／
実在の企業名・読める看板文字。
【⚠️構図（最重要・従来どおり）】
背景の上には必ず会話枠・カード・立ち絵が乗る。
・中央下40%＝主題を置かない。暗く平坦に（情報が乗る）
・左右の下端＝細かい描き込みを置かない（立ち絵が立つ）
・上部30%＝ここに主題（空・建物の上部・遠景）
・中央上＝強い模様を置かない（ロゴが乗る）
・⚠️画面全体の明度は落として描く（明るい世界だが、UIが乗るので背景としては引っ込ませる）
【比】16:9
```

## 2. スチル（★今回の主役・大量に作る）

**用途**：クリア時の演出／ストーリーの見せ場／紙芝居風アニメーション。1枚絵をUI側で寄り引き・フェードさせて動かす。

- 比 **16:9**、PNG。**背景込みの一枚絵**（立ち絵と違い透過不要）。
- 保存 `assets/hanaawase/still/<char>/<id>.png`
- ⚠️**構図は自由**（UIが乗らない全画面演出用）。ただし**キャラの不変条件は厳守**。
- ⚠️**表情と手元が見えること**（何をしているか一目で分かる絵にする）。

### 若菜（`still/wakana/`）— 各シチュを時間帯違いで
| id | 内容 |
|---|---|
| `cut_morning` / `cut_day` / `cut_evening` | 茎を水切りしている手元と顔（朝/昼/夕の光） |
| `arrange_day` / `arrange_night` | 花束を組んでリボンを掛けている |
| `handover_day` / `handover_evening` | 客へ花束を差し出す（客は後ろ姿・顔を描かない） |
| `water_morning` / `water_evening` | 如雨露で水をやる |
| `carry_day` | 花桶を抱えて運ぶ |
| `ledger_night` | 閉店後、帳面をつける |
| `smile_close` | 会心の笑み（クリア演出用の寄り） |
| `tired_night` | 一息ついて肩を落とす（未達演出用） |

### レン（`still/ren/`）
`delivery_day`／`delivery_evening`（配達）／`carry_box`（荷を運ぶ）／`help_water`（水やりを手伝う）／
`laugh`（大笑い・耳が立つ）／`serious_night`（真顔で端末を見る）／`handover`（花を受け取る）。

### サブキャラ（`still/<id>/`）— 八重・犬飼・玄・辰巳・内藤
各キャラ**その人の「機能」が伝わる場面**を数枚（例：八重＝店先から呼ぶ／犬飼＝セリ場で枝を掲げる／玄＝黙って豆を置く／辰巳＝競りの声／内藤＝夜の畑で菊を指す）。

### イベント限定スチル（`assets/hanaawase/events/<event-id>/still/`）
イベントの山場用に2〜3枚。⚠️**本編スチルと混ぜない**（イベント終了時に切り離せるように）。

## 3. サブキャラの立ち絵・表情（各キャラ20枚を目標）

## 6. 実務（従来どおり厳守）
- 寸法は**比で指示**（16:9 / 2:3 / 1:1）。ピクセル指定は効かない。
- **1枚ずつ**生成し、**1枚ごとに `HANATSUNE-WORKLOG.md` の進捗表を更新**する。
- 透過は緑クロマキー→ローカル処理（APIキー禁止）。⚠️**輪郭に緑が残らないよう despill を丁寧に**（前回 bustup で緑縁が残った）。
- 参照 `-i`：人間キャラ＝`ref/wakana.png`、獣人＝`ref/ren.png`。**背景には参照を渡さない**。
- 生成物を `~/.codex/generated_images/` に溜めたままリポジトリに混入させない。
- ⚠️**容量**：PNGで保存後、Claude 側で **webp（quality82/alphaQuality100）に一括変換**する（前回 20.8MB→816KB／96%削減）。Codexは**PNGのまま置いてよい**が、1枚が極端に重い場合は減色する。
- ディレクトリ作成・コピーは **PowerShell**（UNCパスでは Bash のファイル作成が通らない＝既知地雷）。
