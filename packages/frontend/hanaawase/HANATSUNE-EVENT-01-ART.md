### 0.1 ⚠️「少しだけ豪華」の定義（本イベントの肝・誤読が多い）

イベント立ち絵は本編より**わずかに豪華**にする。ただし——

| 増やしてよいもの（＝描き込み量） | ⚠️変えてはいけないもの（＝画風） |
|---|---|
| 衣の柄を1種だけ入れる（藤色地に淡い麻の葉、または小さな絞り） | 輪郭線の太さ（本編と同じ太さ均一の墨線） |
| 眼鏡の金縁に細いハイライトを1本 | 影の段数（**1段のみ**。2段にしない） |
| お団子のほつれ毛を数本描き足す | 頭身（2.5〜3頭身） |
| 襟・袖口に生成りの縁取りを1本 | 塗り（フラット塗り。グラデを盛らない） |
| 帯留めなど小物を1点だけ | 彩度・明度の方針（若菜・レンと同じ明るさ） |

⚠️**豪華さ＝描き込み量であって、画風の変更ではない。**
「上質に」「繊細に」「水彩で」「柔らかいタッチで」といった語を**プロンプトに書かない**。
書いた瞬間に若菜・レンと並ばなくなる。

## 1. 参照画像の渡し方（⚠️最重要）

`-i` はローカル画像を参照素材として渡すフラグ。**複数枚は `-i` を繰り返す**。
⚠️**渡すだけでは役割が伝わらない。プロンプト本文で「1枚目は◯◯、2枚目は◯◯」と必ず明示する。**

### 1.1 基本形（きよばあの全カットで共通）

```bash
codex image \
  -i packages/frontend/hanaawase/ref/kiyoba.webp \
  -i packages/frontend/hanaawase/ref/wakana.png \
  --aspect 1:1 \
  -o packages/frontend/assets/hanaawase/events/mago-no-inuma/chara/kiyoba/face_1.png \
  "<プロンプト本文>"
```

⚠️コマンド名・オプション名は環境の画像生成CLIに合わせてよい。
**本書が指定しているのは「`-i` を2枚この順で渡すこと」と「プロンプト本文の中身」の2点**であり、
この2点を満たせば呼び出し方は問わない。比だけは**必ず**指示すること（§12.15-1）。

### 1.2 ⚠️プロンプト本文の冒頭に必ず置く「役割宣言ブロック」

きよばあの8枚（立ち絵2＋表情6）すべてで、プロンプトの**先頭**にこれをそのまま貼る。

```
【参照画像の役割】
1枚目（kiyoba.webp）＝ このキャラクターが「誰であるか」だけを取る。
  すなわち：白髪のお団子／丸眼鏡／たれ目／笑い皺／赤らんだ頬／藤色の衣。
  ⚠️1枚目は水彩調のイラストだが、その水彩の質感・にじみ・かすれ・淡い色調は
  一切再現しないこと。1枚目から取るのは造形だけで、描き方は取らない。
2枚目（wakana.png）＝ この絵の画風・線・塗り・頭身に完全に合わせる。
  すなわち：太さの均一な墨色の輪郭線／フラット塗り＋影は1段だけ／
  2.5〜3頭身のポップなデフォルメ／大きくはっきりした瞳。
  ⚠️最終的な絵は、2枚目と並べて同じ絵師が描いたように見えなければならない。
```

⚠️この宣言を省くと**きよばあだけ水彩調になり、若菜・レンと並べたとき浮く**。
本イベント最大の事故要因なので、**8枚すべてで貼る**（1枚目だけ貼って以降省略しない）。

### 1.3 背景3枚での参照画像

背景は**キャラ参照を渡さない**。`-i` なしで生成する。
理由：`wakana.png` を渡すと背景までキャラのデフォルメ画風になり、§12.75.1 の「キャラほど強くデフォルメせず、線は細く面で描く」に反する。

## 2. 共通画風ブロック（きよばあ8枚に貼る定型）

役割宣言ブロック（§1.2）の直後に、これもそのまま貼る。

```
【画風（厳守）】
ポップなデフォルメのアニメ調イラスト。2.5〜3頭身。
太さの均一な墨色（#2b2620）の輪郭線。フラットな塗りで、影は1段だけ。
目は大きく、白目と虹彩がはっきりしたアニメ的な瞳。表情は大げさに。
配色は明るくポップ。基調は朱・藍・苔緑・金・生成り。
背景は完全な透明（アルファ）。影の落ちる床や地面を描かない。

【禁止】
写実的な頭身・リアルな描写／グラデーションを盛ること／
ツヤツヤした立体的なハイライト／写実的な皺や肌の質感の描き込み／
水彩・色鉛筆・アナログ画材風の質感／かすれた線・にじみ／
くすんだ色調・セピア・落ち着いた渋い配色／既存作品のキャラクターに似せること。

⚠️高齢のキャラクターだが、渋く・暗く・大人びた画風にしないこと。
若菜（2枚目）とまったく同じ明るさ・同じ彩度・同じ線で描く。
年齢は「画風」ではなく「造形（白髪・皺・背丈）」だけで表現する。

【造形（きよばあ・全カット共通。1点も変えない）】
80歳前後の小柄な女性。背は低く、やや前かがみ。ただし弱々しくはなく、足取りは軽い。
・白髪を後頭部でひとつにまとめたお団子。ほつれ毛が数本。⚠️位置は「後頭部のやや高い位置」で全カット固定
・丸眼鏡。細い金縁。⚠️レンズは真円。楕円・角丸四角にしない。全カットで同じ形・同じ大きさ
・たれ目。茶色い瞳
・目尻と額に笑い皺をはっきり描く（⚠️太めの短い線で数本。写実的な皺の描き込みにしない）
・頬に赤み
・藤色（#8e7cb0 系）の上着＋生成りの襟。⚠️藤色は全カット共通
・イベント用にわずかに描き込みを増やす：
  藤色地に淡い麻の葉の小紋を控えめに／襟と袖口に生成りの細い縁取り／
  眼鏡の金縁に細いハイライトを1本。
  ⚠️描き込みを増やすのはこの3点だけ。線の太さ・影の段数・頭身は若菜と完全に同じに保つ。
```


## 8. ⚠️失敗しやすい点と回避

| # | 症状 | 原因 | 回避 |
|---|---|---|---|
| 1 | **きよばあだけ水彩調になる** | `ref/kiyoba.webp` は水彩画。参照として渡すと**造形だけでなく描き方も引きずられる**。これが本イベント最多の事故 | §1.2 の役割宣言ブロックを**8枚すべて**の冒頭に貼る。「1枚目の水彩の質感・にじみ・淡い色調は一切再現しない」と明文で書く。それでも出るなら `kiyoba.webp` を外して**文字指定だけで**造形を書き、`wakana.png` 1枚のみ渡して生成する |
| 2 | **高齢＝渋い画風になる** | モデルは「老人」から落ち着いた色調・写実的な皺・セピアを連想する。放っておくと必ずこうなる | §2 の禁止に「くすんだ色調・セピア・渋い配色」を明示済み。加えて「年齢は画風ではなく造形だけで表す」と書く。⚠️皺は**太めの短い線で数本**と本数まで指定する |
| 3 | **眼鏡の形が枚ごとに変わる**（真円→楕円、細縁→太縁、有無が揺れる） | 表情が変わると眼鏡も再解釈される。特に face_4（ずれる）で崩れやすい | 全カットで「丸眼鏡・真円・細い金縁」を毎回書く。face_4 では「**位置だけがずれ、形と大きさは他の5枚と同じ**」と明記。⚠️1枚でも崩れたら、その1枚だけ作り直す（全部作り直さない） |
| 4 | **お団子の位置がぶれる**（頭頂／後頭部低め／横に移動） | 顔の角度が変わると髪もつられて動く | 「後頭部のやや高い位置」と**固定表現で毎回書く**。6枚並べて上下位置を確認する（§7.2） |
| 5 | 6枚の顔の大きさ・位置が揃わない | 表情ごとに構図が変わる | §3 の「カットの形式」ブロックを全枚に貼り、「同じ顔の表情差分である」と明言する。並べて確認（§7.2） |
| 6 | 「豪華に」と書いた結果、**画風ごと変わる** | 「豪華」「上質」「繊細」は画風の指示として解釈される | ⚠️これらの語を**プロンプトに書かない**。増やすものを §0.1 の3点に**具体名で**限定する |
| 7 | 立ち絵に地面・影が付く | 立ち絵の指示だけでは接地が描かれがち | 「背景は完全な透明」「地面・影・床を描かない」を毎回書く |
| 8 | 立ち絵が「弱々しい老人」になる | 「80歳・前かがみ」から介助が必要な姿を連想する | 「足取りは軽い」「杖は持たせない」「よろけさせない」を毎回書く。⚠️pose_b で特に出る |
| 9 | 背景の中央に主題が来て**会話枠で潰れる** | 絵として良い構図＝中央に主題、が既定の挙動 | §5 の構図ブロックを毎回貼る。⚠️生成後に必ず**半透明矩形を重ねて確認**（§7.4） |
| 10 | 背景が明るく綺麗すぎて**立ち絵が沈む** | 「観光ポスター」的な絵になる | 「最初から明度を落として描く」「観光ポスターにしない」を毎回書く。⚠️UI側で暗くして誤魔化さない |
| 11 | 看板に読めそうな文字・実在の店名が出る | 商店街を描くと文字が生えるのは既定の挙動 | 「読めない程度に潰した色面と抽象的な筆致」と書く。生成後に等倍で文字を探す |
| 12 | 3枚の背景で季節・時刻・様式が揃わない | 1枚ずつ独立に生成するため | §5 の「世界観の共通条件」を3枚に貼る。⚠️3枚揃った時点で必ず**並べて**確認する |
| 13 | 生成枠を使い切って途中で止まる | 画像生成はテキストの3〜5倍の速度で枠を消費する（§12.15-2） | ⚠️候補を並列で10枚出さない。**1枚ずつ確認しながら**進める。**1枚生成するごとに WORKLOG を更新**する（§9） |
