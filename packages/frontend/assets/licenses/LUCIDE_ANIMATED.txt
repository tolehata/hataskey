The Vue components used by HataSNSCordUI preserve the icon geometry and
animation definitions from the source project. Icon shapes are based on
Lucide; see LUCIDE.txt in this directory for the Lucide and Feather notices.
The Vue port's README grants use of its components in personal and commercial
projects and identifies the animations as ports of the MIT-licensed source.
Its port-only Baby icon is not included here.
