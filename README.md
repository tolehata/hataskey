# Hataskey

**超高機能で独自UIを備え、使いやすさを追求したカスタムCherryPickフォークです**

## 概要

- **ベースバージョン**: Misskey 2026.9.1（CherryPick ベース）
- **最新バージョン**: [hata-12.8.1](./HATA-CHANGELOG.md#hata-1281)
- **チェンジログ**: [HATA-CHANGELOG.md](./HATA-CHANGELOG.md)

## Hataskeyが使用されているインスタンス

- [はたすきー](https://misskey.hatachanoima.net/)

## ベースプロジェクト

- [Misskey](https://github.com/misskey-dev/misskey) by misskey-dev
- [CherryPick](https://github.com/kokonect-link/cherrypick) by kokonect-link
